## Projets

**[honeybee-gwas-pipeline](https://github.com/romainkpakou/honeybee-gwas-pipeline)**
Pipeline Nextflow DSL2 WGS→GWAS (16 modules) appliqué à la conservation de l'abeille noire *Apis mellifera mellifera* : GATK Best Practices, PLINK2, ADMIXTURE, GWAS par modèle mixte GEMMA.

**[scrnaseq_pipeline](https://github.com/romainkpakou/scrnaseq_pipeline)**
Pipeline Nextflow DSL2 modulaire pour l'analyse single-cell RNA-seq (10X Genomics) : QC, clustering UMAP, annotation cellulaire automatisée, trajectoires Slingshot, rapport HTML dynamique.

**[single_cell_pbmc](https://github.com/romainkpakou/single_cell_pbmc)**
Analyse scRNA-seq complète du jeu PBMC 3k avec Seurat : annotation de 9 populations immunitaires (2 638 cellules) et reconstruction de la différenciation lymphocytaire T.
