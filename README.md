## Projets

**[honeybee-gwas-pipeline](https://github.com/romainkpakou/honeybee-gwas-pipeline)**
Pipeline Nextflow DSL2 WGS→GWAS (16 modules) appliqué à la conservation de l'abeille noire *Apis mellifera mellifera* : GATK Best Practices, PLINK2, ADMIXTURE, GWAS par modèle mixte GEMMA.

**[scrnaseq_pipeline](https://github.com/romainkpakou/scrnaseq_pipeline)**
Pipeline Nextflow DSL2 modulaire pour l'analyse single-cell RNA-seq (10X Genomics) : QC, clustering UMAP, annotation cellulaire automatisée, trajectoires Slingshot, rapport HTML dynamique.

**[single_cell_pbmc](https://github.com/romainkpakou/single_cell_pbmc)**
Analyse scRNA-seq complète du jeu PBMC 3k avec Seurat : annotation de 9 populations immunitaires (2 638 cellules) et reconstruction de la différenciation lymphocytaire T.

**[cnv-clinical-pipeline](https://github.com/romainkpakou/cnv-clinical-pipeline)**
Détection et priorisation de CNV dans un panel de gènes cardiomyopathie/arythmie, sur le callset public 1000 Genomes : filtrage bedtools, annotation fonctionnelle via l'API Ensembl VEP, rapport R Markdown.

**[sequence-classifier-app](https://github.com/romainkpakou/sequence-classifier-app)**
Application Streamlit de classification de séquences protéiques sans alignement préalable (Sequence Graph Transform), réduction dimensionnelle PCA/t-SNE, clustering interactif et logos de séquence.

**[splicing-cardio-encode](https://github.com/romainkpakou/splicing-cardio-encode)**
Jonctions d'épissage candidates dans 5 gènes cardiovasculaires à partir de RNA-seq public ENCODE (ventricule/oreillette), extraction samtools/regtools et comparaison aux exons connus via l'API Ensembl.
